# Andromeda Prod: database and parsers

Публичный репозиторий с моделями и миграциями базы Andromeda, предметной логикой/онтологией, импортёром нормализованных данных, исходниками парсеров и безопасным снимком данных МГТУ за кампанию 2026.

Здесь нет веб-сайта, визуализатора, HTTP API, локального кластера PostgreSQL или дампа базы. Публикуется схема и нормализованные записи, но не сырые списки поступающих и не исходные файлы документов.

## Состав

- `database/academic-data/` — текущий отдельный модуль академических данных: PostgreSQL-модели, Alembic-миграции, source evidence/provenance, temporal-факты, правила, классификация предметов, контракты и offline bundle importer. HTTP API и его приложение не включены.
- `database/legacy-andromeda/` — исходные ORM-модели, Alembic-история и предметные модули исходного монолита для переноса и сопоставления с новой схемой.
- `parsers/source-tree/` — исходный код адаптеров и парсеров университетов, включая парсеры МГТУ. Сборный orchestration runner не включён: он связан с локальным ingest-приложением и загруженными исходными PDF.
- `data/bmstu-2026/` — нормализованные JSONL-записи по МГТУ, очищенный манифест источников, ручная проверка и ограничения снимка.
- `docs/SOURCES.md` — карта типов информации и официальных источников.

## Снимок МГТУ

Выгрузка относится к головному кампусу в Москве и была собрана 3 октября 2026 года. Включено 53 направления, 77 кафедр, 152 профиля, 127 предложений приёма, 940 пулов мест/квот, 152 записи учебных планов (файлы обработаны для 127), 14 165 строк дисциплин, 81 набор экзаменационных требований, 340 строк стоимости и 783 агрегированные исторические записи. Это не полный охват источников и не официальный набор проходных баллов за 2026 год.

Олимпиадные записи не входят в данные. Сырые PDF/XLS/XLSX и любые исходные файлы конкурсных списков не публикуются. В manifest сохранены стабильные ключи и безопасные метаданные; локальные пути, временные Yandex download URLs и URL-параметры удалены. Документ приложения 8.1, предоставленный владельцем проекта, не включён; его значения представлены в нормализованной выгрузке, а локальный адрес заменён на отсутствие URL.

## Начало работы с модулем академических данных

См. [`database/academic-data/README.md`](database/academic-data/README.md) для установки, offline-валидации bundle и режимов импорта. Команда `bundle import --dry-run` не открывает подключение к базе. Для записи в БД требуется отдельный PostgreSQL и явный флаг `--commit`.

Парсерные модули находятся в `parsers/source-tree/src/andromeda/ingestion`. Это сохранённые исходники адаптеров. Они не составляют отдельный production runner и не запускаются автоматически из этого репозитория.

## Безопасность публикации

Не коммитьте `.env`, DSN, дампы PostgreSQL, содержимое каталога данных PostgreSQL, исходные PDF/таблицы, списки абитуриентов, токены и приватные URL. Такие файлы исключены через `.gitignore`; открытые источники перечислены в карте источников.
