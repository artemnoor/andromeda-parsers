# BMSTU 2026 normalized data

Файлы JSONL содержат по одной записи на строку и используют стабильные `external_key`/source keys. Подробное описание области, ограничений и очистки: [`REPORT.md`](REPORT.md). Источники и тип извлекаемой информации: [`../../docs/SOURCES.md`](../../docs/SOURCES.md).

Пакет содержит только нормализованные записи и публичные метаданные provenance. Исходные документы, персональные данные абитуриентов, временные ссылки скачивания и PostgreSQL dump исключены.
