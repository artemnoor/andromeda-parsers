# Legacy Andromeda database and domain model

Здесь сохранены SQLAlchemy-модели, исходные Alembic-миграции и доменные модули исходного Andromeda backend. Папка нужна для изучения и безопасного переноса существующих сущностей и онтологии. Дамп или файлы данных БД сюда не копировались.

Текущая отдельная схема нормализованных академических данных находится в `../academic-data/`. Это не две равноправные точки записи: перед любым переносом нужно сверяться с миграциями активного academic-data модуля.
