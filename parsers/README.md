# Parser source tree

Исходники адаптеров и парсеров сохранены под `source-tree/src/andromeda/ingestion/`. Для МГТУ присутствуют каталог, карточки профилей, планы, документы приёма, сведения абитуриентам, стоимость и метаданные итоговых источников. Также сохранены общие ingestion-контракты и другие имеющиеся адаптеры.

Веб-визуализатор и старый orchestration runner не включены. Парсерные модули не были запущены при подготовке публичного репозитория; нормализованный снимок уже находится в `data/bmstu-2026`. Исходные PDF/таблицы, локальные fixtures и raw-каталоги не публикуются. Модуль олимпиадного парсера как исходный код может присутствовать, но никакие олимпиадные записи в снимок не добавлялись.
